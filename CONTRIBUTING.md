# Contributing

Use Node.js 22+ and the README development commands. Make focused changes and add
synthetic behavior fixtures for parsing, path resolution, portability and privacy.
Do not execute repository code or fetch target URLs during a test.

Bug reports should include versions, the command, expected/actual output and a
small sanitized reproduction. Do not attach private documentation, credentials
or full absolute filesystem paths. Feature requests should describe the workflow
and supported syntax needed. 中文反馈同样欢迎。

Document parser uncertainty and preserve deterministic JSON schema behavior.
Contributions use MIT. Browser screenshots and generated local audits stay ignored.
