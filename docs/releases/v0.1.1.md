# Doc Route v0.1.1

Maintenance release draft, 2026-11-06 (Asia/Shanghai).

修复：行内代码中的 HTML 注释示例会隐藏后续真实链接、标题，可能导致检查错误通过。
现在保留这些内容的检查，并正确处理真实注释里的反引号和未配对的反引号。

Fix a false clean result when a literal HTML comment opener appears in inline
code. Previously, this document could pass without checking the missing page:

```markdown
`<!--` [Broken link](missing.md)
```

It now reports `MISSING_TARGET` and exits 2 with the default error gate. Later
headings keep their anchors and original line numbers. Real HTML comments still
close at their first literal terminator; unmatched backtick runs remain text.
Single-line code spans remain the supported scope; this is not a full CommonMark parser.

The valid quickstart example now keeps every local link inside its own root;
scanning `examples/valid` no longer fails on a link to the parent project README.
The offline package check also runs that installed example to prevent recurrence.

Requires Node.js 22+. Install the attached tarball:

```sh
npm install --global ./doc-route-cli-0.1.1.tgz --ignore-scripts
docroute --help
```

32 local tests, strict build, static checks and offline package installation
cover this change. Three-platform CI at the release commit is required before
tagging. JSON schema 1, privacy filtering and offline operation are preserved.
No npm publication is performed; the GitHub release remains a draft.
