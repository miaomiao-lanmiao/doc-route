# Doc Route v0.1.0

Initial release draft, 2026-11-01 (Asia/Shanghai).

- Check local Markdown paths, portable filename case and common anchors.
- Support inline/reference links while ignoring common code/comment regions.
- Export Markdown/JSON/standalone HTML, with bounded discovery and optional CI gates.

Requires Node.js 22+. Install the attached tarball:

```sh
npm install --global ./doc-route-cli-0.1.0.tgz --ignore-scripts
docroute --help
```

Runtime has no npm dependencies or remote URL requests. Parser/CLI/filesystem
tests, build, static checks, offline package installation and three-platform CI
are required. A clean report is bounded evidence; unsupported Markdown/routes
and external URLs still require separate review. No npm publication is performed.
